# MERN Registration (React + Node/Express + MongoDB)

## 1. Prerequisites
- Node.js 18+
- MongoDB running locally (or a MongoDB Atlas URI in backend/.env)

## 2. Start the backend
    cd backend
    npm install
    npm run dev          # runs on http://localhost:5000

## 3. Start the frontend (new terminal)
    cd frontend
    npm install
    npm run dev          # runs on http://localhost:5173

## 4. Test
Open http://localhost:5173, fill the form, submit.
Check saved users at http://localhost:5000/api/users
